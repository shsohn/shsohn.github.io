개인정보처리방침 (Privacy Policy)

시행일: 2026-10-10

1. 이 앱이 하는 일

Hermes Agent tool은 소유자 본인이 운영하는 비공개 서버에서 동작하는 개인용 도구입니다. 소유자 본인의 구글 계정으로 승인한 범위에서만 데이터를 읽습니다.

2. 요청하는 권한

  • Google Calendar 읽기 전용(calendar.readonly): 소유자의 일정 목록 조회
  • Google Sheets 읽기 전용(spreadsheets.readonly): 소유자가 지정한 시트의 값 조회

일정·시트를 생성, 수정, 삭제하지 않습니다.

3. 데이터의 사용·저장·공유

  • 조회한 데이터는 소유자 본인의 개인 분석 보고서를 만드는 용도로만 사용합니다.
  • 데이터는 소유자의 개인 서버에만 저장되며, 제3자에게 제공·판매·공유하지 않습니다.
  • 광고, 프로파일링, 학습 데이터 제공 등 다른 목적으로 사용하지 않습니다.

4. 보관과 삭제

소유자는 언제든 구글 계정의 "서드파티 앱 액세스"에서 접근 권한을 취소할 수 있으며, 서버의 인증 토큰 파일을 삭제하면 모든 접근이 중단됩니다.

5. 문의

이 저장소(github.com/shsohn/shsohn.github.io)의 Issues로 문의해 주세요.

Privacy Policy (English)

Hermes Agent tool is a personal tool run by its owner on a private server. It requests read-only access (Google Calendar: calendar.readonly; Google Sheets: spreadsheets.readonly) to the owner's own data and uses it only to generate the owner's personal reports. Data is stored only on the owner's server and is never shared, sold, or used for advertising or other purposes. Access can be revoked at any time from the Google Account's third-party access settings. Contact: open an issue at github.com/shsohn/shsohn.github.io.
